# 🎓 University Management System

##  Overview
A Java Swing-based project for **INFO 5100 – Application Engineering and Development**, demonstrating object-oriented design and role-based UI interaction.  
Three user roles: **Admin**, **Faculty**, and **Student**.

---

##  Key Features
- Role-based login and navigation  
- CRUD for accounts and profiles  
- Search by **name**, **ID**, or **department**  
- Faculty–Course assignment  
- Admin analytics dashboard  
- Auto data seeding for testing  

---

##  Data Seeding
`DataSeeder.java` preloads:
- 10 students, 10 faculty, 1 admin  
- Department: *Computer Science*  
- Courses: *CS5001 – Algorithms*, *CS5200 – Database Systems*  
- Semester: *Fall 2025*  
- Course offerings auto-generated
